# Полка

Небольшой каталог отзывов на игры. Средняя оценка на карточке считается по отзывам людей на этом сайте, а не берётся из магазина.

Проект учебный и рассчитан на одного человека: отдельные роли тимлида, фронтенда и тестировщика здесь совмещены.

## Что уже работает

- Каталог, поиск, фильтр по жанру и сортировка.
- Регистрация и вход. Пароль в базе хранится как хеш.
- Карточка игры: описание, средняя оценка, гистограмма, отзывы.
- Один отзыв на игру от одного человека. Свой отзыв можно исправить или удалить.
- Добавление игры вручную или из готового списка.
- Если задан ключ [RAWG](https://rawg.io/apidocs), поиск ходит в их API и забирает название, жанр, год, студию и обложку.
- Без ключа поиск идёт по встроенному списку, сайт всё равно запускается.

Демо-вход, он создаётся вместе с базой:

- почта `demo@polka.local`
- пароль `polka1234`

## Стек

- Next.js и React: страницы и формы.
- TypeScript.
- Tailwind CSS и компоненты shadcn/ui.
- SQLite: файл `data/polka.db`, создаётся при первом запуске.
- Node.js 22, встроенный модуль `node:sqlite`.

Как это связано: браузер открывает страницу, сервер читает или меняет SQLite, при поиске новой игры может сходить в RAWG.

## Материалы

- Презентация: `presentation/Polka.pptx`. В заметках к слайдам есть текст выступления.
- Отчёт: `docs/Отчет.docx`.

## Запуск

Нужен Node.js 22.

```bash
npm install
npm run dev
```

Сайт откроется на [http://127.0.0.1:47231](http://127.0.0.1:47231).

Проверки:

```bash
npm test
npm run lint
```

Ключ RAWG необязателен. Если он есть, положи его в файл `.env.local`:

```bash
RAWG_API_KEY=ваш_ключ
```

Пример пустого файла лежит в `.env.example`.

## Где что лежит

- `src/app` — страницы: каталог, игра, вход, «мои записи», о проекте.
- `src/actions` — действия форм: вход, игры, отзывы.
- `src/lib/db.ts` — таблицы и запросы.
- `src/lib/auth.ts` — сессия в cookie.
- `src/lib/rawg.ts` — внешний поиск и запасной список.
- `docs/user-stories.md` — что сайт должен уметь, короткими фразами.
- `docs/report-template.md` — болванка недельного отчёта для преподавателя.

База при первом запуске заполняется восемью играми и отзывами трёх людей. Файл базы в git не коммитится: у каждого он создаётся локально.
